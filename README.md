# MediaHard Engine: АПК «МедиаКонтур» & Core App

**MediaHard Engine** — распределенный программный комплекс, объединяющий высоконагруженный транспортный вещательный слой **АПК «МедиаКонтур»** (`tagil-tv.ru`), генеративное ИИ-ядро видеопроизводства и экспертную B2B/B2C-платформу свободной торговли IT-оборудованием.

Центральным и наиболее сложным элементом репозитория является медиаконтур круглосуточного перехвата, маршрутизации и дистрибуции тяжелых эфирных потоков реального времени.

---

## 🎬 Ядро системы: АПК «МедиаКонтур-Тагил» (`tagil-tv.ru`)

Программный комплекс обеспечивает отказоустойчивый удаленный мониторинг и управление медиапотоками регионального пула СМИ города Нижний Тагил. Система изолирована от внешних сетей на физическом уровне и интегрирована напрямую в вещательные сегменты телерадиокомпании.

### 1. Низкоуровневый захват (Ingest Layer)
Перехват сырых цифровых потоков осуществляется силами фоновых Docker-контейнеров на базе бинарного слоя `FFmpeg`. Захват производится напрямую из изолированных медиа-VLAN ТРК в режиме копирования кадров (`-c:v copy -c:a copy`). Это исключает оверхед на повторное перекодирование видео и минимизирует утилизацию CPU кластера до рекордных **1-2%**:
*   **ТВ-1 (Композитный поток «Продвижение» + врезки «Тагил-ТВ»):** Прямой захват MPEG-TS (UDP Multicast) группы через сетевой интерфейс ноды. Нулевая задержка тракта.
*   **ТВ-2 (Изолированные врезки «Тагил-ТВ» для «ОблТВ»):** Сквозной перехват мультикаст-группы через сетевой интерфейс ноды. Предназначен для контроля доставки сигналов на головную станцию в Екатеринбург.
*   **Радио Тагила (Врезки в «Радио России»):** Потоковый захват аудиосигнала с эфирного радиопульта с транскодированием на лету в веб-стандарт `libfdk_aac` для совместимости со всеми HTML5-плеерами.

### 2. Агрегация и Раздача (Egress Layer)
Захваченные потоки внутрисетевым push-методом терминируются на медиасервере **SRS (Simple Realtime Server)** в Docker. Выдача контента в единую веб-панель мониторинга руководства осуществляется по протоколу **WebRTC** с гарантированной задержкой **менее 1 секунды** (с резервным переключением на адаптивный HLS вне локального периметра).

## 💿 Инфраструктурный фундамент (High Availability)

Для обеспечения круглосуточного вещания (`24/7/365`) без риска прерывания эфирных потоков развернута отказоустойчивая промышленная ИТ-инфраструктура:
*   **Вычислительное ядро:** Асимметричный кластер виртуализации **Proxmox VE 9.1.1** (две тяжелые физические ноды).
*   **Сетевой арбитр (Кворум):** Исключение риска разделения кластера (*split-brain*) реализовано через внешний легковесный хост-арбитр **QDevice** (`corosync-qnetd`), изолированный в виртуальной машине Hyper-V под управлением Windows 10 Pro.
*   **Хранилище данных:** Кластерная распределенная файловая система **Ceph**. Данные конфигураций, логи и DVR-архивы вещания застрахованы на уровне пулов CephFS с избыточным распределением.

## 💎 Смежные модули экосистемы MediaHard

### 1. Распределенный ИИ-конвейер (Генеративный слой)
Автоматизированный многоконтейнерный контур для постобработки и генерации видеопрезентаций:
*   **Детекция:** Локальный биометрический поиск лиц через `Buffalo_L (InsightFace)` и распознавание объектов через `YOLOv8-n` [1.8].
*   **Инференс:** Синтез таймлайнов через LLM `Gemma2:9b-it` (Ollama), генерация недостающих сцен через `SDXL Turbo` [1.8]. Высокоскоростной речевой синтез на C++ через `Piper TTS` и фоновый автозвук через `MusicGen-Small` [1.8].

### 2. Экспертный B2B-Маркетплейс (Коммерческий слой)
Платформа для купли-продажи серверного и вещательного оборудования с подтвержденным ресурсом. Находится в стадии миграции с Legacy-скриптов на чистом PHP на строгую архитектуру **DDD (Domain-Driven Design) в Symfony 8.3 / 9.x**. Оркестрирует систему **«Цифровых паспортов исправности»** (JSON-логи тестов SMART/MemTest86 + видеозаписи упаковок оборудования), данные которых верифицируются и защищаются внутри CephFS.

## 📂 Структура репозитория и IaC
*   `compose.yaml` — декларативное описание многоконтейнерной среды АПК (SRS, Nginx, FFmpeg) [1.8].
*   `/config/srs.conf` — низкоуровневая конфигурация портов, RTC и HLS медиасервера [1.8].
*   `/web/index.html` — легковесная фронтенд-панель оперативного мониторинга на базе плеера Clappr [1.8].
*   `/src` — исходный код ядра маркетплейса на Symfony.
*   `/wiki/ops` — база знаний Runbooks, включающая сценарии выживания Ceph и экстренного сброса Corosync [1.8].
